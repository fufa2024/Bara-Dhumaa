# Barumsa Bara Dhumaa (Android app)
Editor: Fufa Basha Hordofa · Source: Dan Bible College.

## Build the APK for free (no Android Studio needed)
1. Create a free account at github.com and make a new repository (e.g. bara-dhumaa).
2. Upload ALL files of this folder (including the hidden .github folder) to the repository (Add file > Upload files). Easiest: unzip, then drag everything in.
3. Open the "Actions" tab > "Build APK" > wait ~5 minutes (or press "Run workflow").
4. Open the finished run > Artifacts > download "Barumsa-Bara-Dhumaa-APK" > unzip > app-debug.apk.
5. Send app-debug.apk by Telegram/WhatsApp; on the phone allow "install unknown apps" and install.

## Edit content
Edit app/src/main/assets/content.js (chapters) and re-upload; Actions builds a new APK.
Change the editor name in index.html (function credits) and the footer line.
